## Deskripsi Project
Project ini merupakan tugas praktikum untuk membuat tampilan antarmuka aplikasi yang terinspirasi dari Gojek menggunakan React Native dan Expo.

Tampilan terdiri dari header, layanan populer, banner promo, restoran terdekat, dan navigasi bagian bawah.

## Teknologi yang Digunakan
- React Native
- Expo
- JavaScript
- StyleSheet
- Flexbox

```text

```

## Fitur Tampilan
1. Header dengan sapaan dan lokasi.
2. Kolom pencarian.
3. Grid layanan Go-Ride, Go-Food, Go-Send, dan Go-Play.
4. Banner promo horizontal.
5. Daftar restoran terdekat.
6. Bottom navigation Home, Activity, Inbox, dan Account.

## Konsep yang Dipelajari
- Membuat komponen React Native secara terpisah.
- Menggunakan StyleSheet.create().
- Mengatur layout menggunakan Flexbox.
- Menggunakan ScrollView horizontal.
- Mengatur warna, ukuran teks, margin, padding, dan shadow.

## Cara Menjalankan Project

1. Clone repository:
   `git clone https://github.com/Cecilia186/AP9_Gojek.git`

2. Masuk ke folder:
   `cd AP9_Gojek`

3. Install dependencies:
   `npm install`

4. Jalankan Expo:
   `npx expo start`

5. Scan QR Code menggunakan Expo Go.
